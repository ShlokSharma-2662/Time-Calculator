## Project surfaces

- **Web app (primary):** `src/` — React 19 + Vite SPA.
- **Optional API:** `server/` — Express 5 JWT auth + JSON file persistence.
- **Mobile companion:** `mobile/` — Expo app that reads Firebase data.

## Where this wiki lives

This `wiki/` folder is intentionally structured so teams can:

1. keep docs versioned in the same repository, and
2. copy or sync these pages into a GitHub Wiki repo when publishing externally.
